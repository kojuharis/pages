# Testing Pages

A simple web application created for testing purposes. This project provides a basic HTML/CSS/JavaScript structure that can be used to test various web technologies and functionalities.

## Features

- **Responsive Design**: Mobile-friendly layout that adapts to different screen sizes
- **Interactive JavaScript**: Testing utilities and interactive elements
- **Form Validation**: Client-side form validation testing
- **Local Storage Testing**: Browser storage functionality testing
- **API Testing**: External API call testing capabilities
- **Navigation**: Multi-page structure for testing navigation

## Files

- `index.html` - Main landing page
- `test.html` - Dedicated testing page with various test functions
- `styles.css` - Responsive CSS styling
- `script.js` - JavaScript utilities and interactive functionality

## Usage

1. Open `index.html` in a web browser
2. Navigate to the test page for advanced testing features
3. Open browser developer tools to see console output from tests
4. Use the interactive buttons to test various functionalities

## Testing Features

- Basic DOM manipulation testing
- Form validation testing
- Local storage functionality testing
- External API call testing
- JavaScript utility functions
- Console logging for debugging
